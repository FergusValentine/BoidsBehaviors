# BoidsBehaviors

This project consists of boid steering behavior implementations: "https://en.wikipedia.org/wiki/Boids", rendered using the openGL graphics library.

In this project I use a simplified renderer composed of vertex array objects to render boid Triangles.

This work is unfinished.
